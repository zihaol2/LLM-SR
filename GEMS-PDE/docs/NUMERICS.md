# 数值残差、拟合、复杂度与基线口径

## 空间窗口残差

对每个输出，候选方程表示为：

\[
u_t=\sum_j c_j\phi_j(u,v,x;\theta_j).
\]

时间三次样条估计观测的时间导数；空间五次样条计算表达式中的一至四阶空间导数。然后使用 10 个相互重叠的 sin⁴ 空间测试窗口：

\[
y_{k,t}=\int w_k(x)\widehat{u_t}(x,t)\,dx,\quad
A_{(k,t),j}(\theta)=\int w_k(x)\phi_j(x,t;\theta_j)\,dx.
\]

当前均匀网格用 `Phi.T @ field` 实现加权求和，权重已含 dx。残差为 `A(theta) @ c - y`。

**这是空间投影式积分残差。** 代码没有分部积分将高阶场导数转移给测试函数；时间方向也没有弱积分。高阶导数仍在数值计算链中。不要据此声称消除了高阶导数估计误差。

## 变量投影

给定 theta 后，所有线性外系数用列归一化后的 `np.linalg.lstsq` 求解。非线性 `scipy.optimize.least_squares` 仅优化 theta；每次残差评价都会重新求解最佳 c：

\[
\min_\theta\min_c\|A_{train}(\theta)c-y_{train}\|^2.
\]

内部参数边界 [-8,8]；通用粗初值为 0.25、0.5、1、2，另有父参数继承与新增参数扰动；按训练残差选至多两个起点。每个起点的 `max_nfev` 为短拟合 12 或完整拟合 45。外层系数默认不加边界，不使用 L1 稀疏惩罚。没有内部参数时直接求线性最小二乘。

“联合拟合”指新结构中的全部内部参数和全部外系数一起重新估计，不是只拟合新加入项。`max_nfev=45` 不是整个候选全过程恰好 45 次底层函数调用，粗初值评价及数值差分也有计算成本。

## 训练、验证与最终 MSE

轨迹内部均匀抽取约 112 个时刻，均匀挑 32 个作验证，其余 80 个作训练。每个时刻投影十个空间窗口，默认每输出得到 800 个训练残差、320 个验证残差。这些残差有时空相关，不能视为独立样本。

theta/c 在训练子集拟合，验证误差参与结构及多初值结果的选择。因此验证集是模型选择数据，非独立测试集。时间样条使用整条轨迹构建，预处理也不是严格隔离的训练/测试流水线。

最终冻结内部参数与结构后，在全部观测时刻重拟合线性系数并报告 MSE；双输出按各自 MSE 平均。**报告的 MSE 不是 32 个验证时刻的测试 MSE，也不是数值解 PDE 后的轨迹预测误差。**

80/32 是计算预算与覆盖的工程选择，不是理论最优比例。不同抽样可能改变参数和结构排序。

## 复杂度与结构评分

保持原 42/44 规则：规范化消除无意义标量别名；D 调用记 2，普通算术记 1，幂记 2，一元函数记 1；加上不同内部参数、外系数、外乘法和项间加法。D 不作完整乘积法则展开后计复杂度。

\[
S(M)=\left(\frac{MSE_{val}}{E[y^2]}+10^{-14}\right)e^{0.1C(M)}.
\]

复杂度作用于候选结构评分，不等价于对系数的稀疏收缩。校正仍可能接受更复杂、但残差下降很多的方程。

## 三种实现的区别

| 项目 | 当前 GEMS-PDE | 本包适配基线 | 本地原版五题 spec |
|---|---|---|---|
| 空间数值导数 | 五次样条 | 同一代码 | 五次样条 |
| 时间导数 | 观测时间三次样条 | 同一代码 | 观测时间三次样条 |
| 空间积分 | 十窗口加权求和 | 同一代码 | 十窗口 trapz |
| 优化 | 变量投影 + least_squares | 同一代码 | 单初值 BFGS 直接优化全部参数 |
| 参数起点 | 通用起点 + 父参数继承 | 通用起点 | spec 设定的固定初值 |
| 参数共享 | 节点默认独立 | 同一输出可共享内部参数 | 随原生成函数表达式 |
| 结构产生 | 图目录 + 持久档案编辑 | LLM 完整函数 | LLM 完整函数 |
| 额外完整邻域校正 | 有 | 无 | 无 |

因此，本包基线共享残差和拟合器，但不声称与原版数值实现完全相同。校正也可以作为后处理接到基线之后；当前没有进行这种等计算预算消融。

## 已知数值风险

先组合再分别数值求导，未强制保持连续代数/微分恒等式。例如 D(u²,2) 与 2D(u·uₓ,1) 在特征矩阵中可能存在小差异，较大相反系数会利用差异降低残差。参数接近退化值也会产生拟合很好但结构较差的方程。历史结果按原口径保留，没有事后吸附参数、清理真解之外项或更换评分器。
