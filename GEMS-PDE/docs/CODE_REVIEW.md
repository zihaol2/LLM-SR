## 自动检查内容

`python -m unittest discover -s tests -v` 覆盖：

1. 五题数据划分与窗口投影；
2. 规范化复杂度和导数上限；
3. 合成信号上的非线性参数与线性系数恢复；
4. 持久档案保留高误差部分方程；
5. 完整单步邻域的枚举数量和唯一性；
6. 每个邻居完整拟合以及二倍接受门槛；
7. 基线参数共享解析及拒绝导入等非数学程序；
8. 原 Pareto 核心的前沿更新和提示生成；
9. 搜索模块不导入参考评分器；
10. 恢复拒绝变更的配置；
11. 参考文件解析前要求结果冻结；
12. 格式失败 usage、无密钥落盘与精确离线缓存；
13. 合成数据、模拟 LLM 下的完整搜索→校正→基线→恢复→评价。

另外执行发布快照哈希校验、保存方程的残差重算、五题 Jaccard 重算、可安装包构建与脱离历史项目目录的运行检查。具体数值核对输出见 `artifacts/validation_summary.json`。

本地结果：13 项测试通过；18 个输出的 MSE 重算最大相对差约 4.33e-12；最新方法/基线平均 Jaccard 分别为 0.8428571429 / 0.3610389610；全部 11,532 条邻域拟合记录及 6 次接受编辑校验通过。数值核心的六个函数与历史实现 AST 一致，五题目标向量及扩散特征列与历史实现逐元素一致。

GitHub Actions 已配置 Linux/Windows 离线检查，但本地通过不表示远端 Actions 已实际执行。尚未进行新增的真实 LLM 端点可用性或五题在线实验。

## 保留的研究问题

本次整理没有修改残差定义、重建数值算子或提高复杂度权重。窗口积分仍在高阶数值求导之后；同轨迹验证和等价项近抵消风险仍然存在。校正是有限单步邻域搜索，不能保证全局最优；基线未获得相同的额外数值校正预算。这些是方法的现有边界，不应在发布说明中隐藏。
