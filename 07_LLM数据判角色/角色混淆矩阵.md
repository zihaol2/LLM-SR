# 07 只给数据判角色 —— 混淆矩阵

- 模型：deepseek-v4-flash（TeamoRouter 网关），temperature=1.0，thinking 关闭
- 规模：5 个方程 × 5 个种子；Predator_Prey 有 2 个场，故共 30 条「场-种子」判断
- 输入：只给数据的统计卡（范围/符号/谱/漂移/样例行/互相关），不给物理描述、不要求方程

## 标签口径

真值是具体角色名，模型回答是自由文本，两边不在同一标签空间，因此定义一套与学科无关的宏观角色类别：

| 宏观类别 | 含义 | 真值中属于该类 |
|---|---|---|
| DENS | 密度 / 浓度 / 扩散标量（含概率密度、温度热、示踪物） | population density、morphogen concentration、traffic density、prey density、predator density |
| AMPL | 序参量 / 模与波的振幅 | order parameter |
| DERIV | 派生量 / 次级量（通量、速率、梯度幅值） | 无 |

归属规则：按回答中**最先出现**的宏观类别归类；温度/热并入扩散标量类；双义回答（交通 seed2「pulse/wave amplitude」、捕食者 f1 seed4「concentration/order parameter」）按首位术语计并在明细中标注。

## 结果

- **具体角色名命中：0/30 = 0%**。模型从未说出任何一个真值角色名。
- **宏观类别命中：25/30 = 83.3%**。
- 平凡基线（每问都答“密度/浓度类”）：25/30 = 83.3%；**二者完全相同** —— 模型在宏观类别这一层拿到的分数，等于不做任何判断、一律回答“密度/浓度类”所拿到的分数，没有额外增益。
- 唯一不是靠多数类蒙对的是 Forced_Swift_Hohenberg（order parameter），5/5 答成“波的振幅/不稳定模”。
- 被系统性判错的是 Predator_Prey f2（真值 predator density），5 次里 4 次答成“派生量/次级量”；另有 Predator_Prey f1 的 seed2 把 prey density 答成了“缓慢演化的主模态振幅”。

## 怎么读这张图

模型给出的全是「浓度 / 密度 / 温度 / 振幅 / 概率密度」这类**跨学科通用词**，没有一次落到具体角色名上。也就是说，在匿名数据下它能恢复的是**扩散标量 vs 图案幅度**这一层粗糙区分，而且这一层区分本身并不优于“一律答密度/浓度”的多数类基线；再往下的具体角色（population / morphogen / traffic / prey / predator）完全不可辨识。

逐条原始回答见 `角色混淆矩阵_明细.csv`（含每条的模型原文，可自行核对归类）。
