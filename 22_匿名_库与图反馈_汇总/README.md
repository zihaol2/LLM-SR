## 一、设定

**完全匿名**在这里指：

- prompt 里没有任何结构先验、没有任何学科名词（所有文本经词表扫描，0 命中）；
- 起点没有机制库——库只能由搜索自己从数据里长出来；
- 变量只有形状信息：`x1`（空间坐标）、`f1`（场）、`f1_t`（时间导数）。

**图的细粒度反馈**指：每轮把当前最好拟合的四联诊断图交给视觉模型读——
残差场、每个测试窗口的误差、残差随场值的变化、残差谱；同时给出对应的测量数值。

## 二、结果（同一问题、同一数据、同一模型、每次 100 个候选）

|---|---|---|---|---|---|---|

## 三、两条读数

**1. 图的细粒度反馈有效——而且是被隔离出来的。**
A3 → A4 两个臂**都是完全匿名、都没有库**，唯一差别就是加了"残差诊断 + 图"这一条通道：
最好 MSE **3.480e-04 → 4.775e-05（7.3 倍）**。同时它把塌缩止住了——A3 的 49 个候选只有
9 个不同的 MSE（同一个式子重复 37 次），A4 是 45/46。

**2. 算子库再加一层。**
A4 → A5：**4.775e-05 → 3.529e-05（1.35 倍）**，库从 0 长到 33 条，多样性保持（94/97）。

## 四、必须披露的一件事

A5 那一臂的**算子提案 prompt 里有一处泄漏**：JSON 格式示例写成了
`d_axis(f1 * (1 - f1), 0, 1)`，而 `f1(1−f1)` 正是真解通量里的因子。

后果是可测量的：去掉这个示例之后（另一臂，库仍由数据长出），
库里的"自限因子"结构从 1 条变成 **0 条**，最好 MSE 从 3.53e-05 变成 1.077e-04。
**所以 A5 的 3.529e-05 应当读作"带一处结构提示"的成绩。**

A3 / A4 两臂没有这个问题（它们的 prompt 里不含该示例）。

## 五、A5 的最佳方程（原文，用于对照）

```python
envelope = np.exp(-((x + 2.5)**2) / 8)
f1_t_pred = ( params[0] * d_axis(f1 * envelope, 0, 1)                    # 窗调制的输运
            + params[1] * d_axis(f1 * (1 - np.tanh(f1)), 0, 1)           # 自限因子的输运
            + params[2] * d_axis(f1*(f1-0.35)*(f1-0.65) * envelope, 0, 1)
            + params[3] * d_axis(f1 * envelope, 0, 2) * f1
            + params[4] * f1 * (1 - f1) * envelope )
```

即：**输运＝某个通量的散度**这一结构是它自己从数据里长出来的；但空间调制长成了
x≈−2.5 处的局部 Gaussian 窗，而真值是全域单调缓坡 `1 − 0.5·tanh x`。
